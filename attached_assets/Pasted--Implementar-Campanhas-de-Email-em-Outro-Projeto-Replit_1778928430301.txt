 Implementar Campanhas de Email em Outro Projeto Replit
1. Arquivos novos — copiar para as mesmas pastas
Arquivo de origem	Destino no novo projeto
server/campaignEmailService.ts	server/campaignEmailService.ts
server/excelParser.ts	server/excelParser.ts
client/src/pages/EmailCampaignsPage.tsx	client/src/pages/EmailCampaignsPage.tsx
Você pode copiar o conteúdo diretamente clicando em cada arquivo na aba de arquivos do Replit.

2. Arquivos existentes — substituir pelo completo deste projeto
Estes arquivos já têm a implementação de campanhas integrada:
 
shared/schema.ts
server/storage.ts
server/routes.ts
client/src/components/AppLayout.tsx
client/src/App.tsx
   
Abra cada um aqui, copie tudo e cole no arquivo correspondente do outro projeto.

3. Instalar pacote npm
No Shell do outro projeto:
npm install xlsx


4. Instalar integração Google Mail
No outro projeto Replit:
1. Vá em Tools → Integrations
2. Busque Google Mail
3. Clique em Install e autorize com a conta Gmail desejada

5. Atualizar o connectionId no emailService
No novo projeto, abra server/campaignEmailService.ts e localize a linha que faz fetch do connector google-mail — ela usa o nome do conector automaticamente, então não precisa alterar o ID, apenas garantir que a integração está instalada.

6. Criar as tabelas no banco
No Shell do outro projeto:
npm run db:push

Isso cria as 3 tabelas novas: email_campaigns, campaign_recipients, campaign_replies.

7. Reiniciar o servidor
# O workflow reinicia automaticamente, ou force pelo painel Replit


Checklist final
*  3 arquivos novos copiados
*  5 arquivos existentes substituídos
*  npm install xlsx rodado
*  Google Mail integração instalada
*  npm run db:push rodado
*  Servidor reiniciado
*  Login como adm → menu lateral → "Campaigns" aparece
